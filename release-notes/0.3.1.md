- **No more "Update links?" dialog when Lecture Companion moves or renames notes.** With Obsidian's *Automatically update internal links* off (Obsidian's default), moving course notes into their folders (first start after 0.1.19) and **Rename a course** stopped at Obsidian's "Update links?" dialog, and links to the moved notes stayed broken if it was dismissed. The plugin now moves the files without that dialog and rewrites the links itself, including markdown-style links (`[text](Courses/Bio.md)`, with `%20` for spaces). With the setting on, Obsidian still moves the files and rewrites every link as before.
- **Links found reliably right after startup.** The one-time move waited only for Obsidian's first "links resolved" signal, which can come before every note is indexed, so some links were missed. It now waits until every note's links are indexed, and also finds links by their full path in the note text.
- The end-to-end tests in a real Obsidian pass again (5/5, checked with *Automatically update internal links* both off and on).
