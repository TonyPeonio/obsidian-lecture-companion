- **Setup checklist.** Shown the first time you open the panel (and with the command *Setup checklist* or Settings → Help): whisper.cpp, the Whisper model, the chat model server and chat model, and the optional course site, each with its live status and a button that fixes it (Install/Detect, Download, *Download* a chat model through Ollama with progress). It recommends models for this computer from the GPU (NVIDIA and its memory, Apple silicon) or the CPU cores and RAM.
- **Try a sample.** See results with nothing installed: a sample lecture (transcript with marks and a question from class, a small generated slide deck, transcript-to-slide links, an example summary, replaced by a real one when a chat model answers).
- **Report a problem.** Command, Settings → Help, and a *Report* link on error notices. Opens a report you review and edit (versions, platform, whisper.cpp and chat model status, settings without tokens or keys, the last 50 log lines; vault and home paths replaced by `<vault>` and `~`), then *Copy* or *Open on GitHub*. Nothing is sent automatically.
- **Moodle** as a course site, besides Canvas, through a personal web service token. A course site is now optional and off by default for new installs (existing Canvas setups stay on Canvas); without one, nothing asks for it and the panel's pull button is hidden. Brightspace, Blackboard and Google Classroom are not supported: they only accept apps registered by the school or Google.
- **OpenAI-compatible servers** (LM Studio, llama.cpp, Jan, vLLM, LocalAI) for summaries and everything else that uses a chat model, streamed. Ollama stays the default. The API's `ollama()` is unchanged.
- **Languages.** *Summary language* (default: the lecture's), and *Translate the transcript of this note*, which adds a translated copy with the same timestamps under its own heading. Panel, commands, setup checklist and notices go through a small translation layer (English only so far); settings descriptions are still inline English.
- **Transcribe audio from a link**: a direct link to an audio or video file is downloaded and transcribed (no streaming-site extraction, no helper programs).
- **Backups** of every affected note before moving course notes into their folders or renaming a course, kept in the plugin folder (newest 10); command *Open the backups folder*.
- **Mac**: install hints and recommendations steer Apple silicon to Homebrew's Metal build.
- **Beta channel**: pre-releases tagged `x.y.z-beta.n` (from `manifest-beta.json`) for BRAT.
- Settings use Obsidian's declarative settings API on 1.13+, so every setting shows in the settings search; older versions get the same settings as before. Minimum Obsidian version is now 1.8.7.
- Lint is clean (0 warnings): Ollama/OpenAI streaming keeps `fetch` (requestUrl cannot stream) with requestUrl as the fallback; the deprecated ScriptProcessorNode fallback is gone (the AudioWorklet loads from a data: URL if a blob: URL is blocked).
- Accessibility: labels for the panel's inputs, meters and toolbar, live regions for status and errors, keyboard-focusable timestamps (Enter plays).
- Desktop-only stays: the plugin loads Node modules and starts whisper-server, which Obsidian mobile cannot do.

Tested: unit tests for every new pure function (report building and redaction, settings migration, Moodle and OpenAI clients with faked HTTP, model recommendations, sample note and PDF, backups, translation, media links, i18n), and interruption tests that stop the chunker and pipeline at random points and check that no audio or text is lost or duplicated. End-to-end tests in a real Obsidian (wdio-obsidian-service) cover course-note migration, course rename with recordings, clickable timestamps, the sample and importing a note; they run in GitHub Actions (E2E workflow, under a virtual display, outside the release gate) and as the opt-in `npm run e2e:obsidian`. One early local run passed 4 of 5; the failing test read the note before the link fix landed and now waits for it; the final versions were not run locally. Not checked in Obsidian: the setup checklist's install/download buttons, Moodle against a real Moodle site, OpenAI-compatible servers against a real server, the settings search on Obsidian 1.13+, the problem report's GitHub page.
