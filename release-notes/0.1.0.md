First release.

- Live lecture transcription through a plugin-managed whisper.cpp `whisper-server` (multithreaded, stopped when idle) or a remote whisper server you already run.
- Transcript streams into the sidebar as you speak, with a progress bar, lag indicator and mic level; written to the lecture note every minute and on stop.
- One-click Whisper model download from the official Hugging Face repository with SHA-256 verification. The whisper.cpp binary itself is found on PATH / Scoop / Homebrew and never downloaded by the plugin.
- Canvas LMS: pull the day's PDF/PPTX slides from Files and Modules of every active course, embed them in the lecture note and extract their text.
- Summaries from Ollama with timestamped key points, definitions, formulas, announcements and review questions.
- Per-lecture notes (`Courses/<course>/<date>.md`) linked from the course note, or sections under date headings in one note per course.
