First release.

**Record and transcribe**
- Live lecture transcription through a plugin-managed whisper.cpp `whisper-server` (one thread per core, stopped when idle) or any whisper server you already run.
- Transcript streams into the sidebar as you speak, with a progress bar, lag indicator and mic level; written to the note every minute and on stop. Recording the same lecture twice appends.
- Auto-stop safety nets: the laptop sleeping, the microphone going away, a maximum length, or a long silence all end the recording and finish the note.
- One-click Whisper model download (official Hugging Face files, SHA-256 verified). The whisper.cpp binary is found on PATH / Scoop / Homebrew / `%LOCALAPPDATA%\whisper.cpp`; on Windows the settings tab detects an NVIDIA GPU and can open the bundled installer script for the CUDA or CPU build.

**Slides from Canvas LMS**
- Pull the day's PDF/PPTX files from the Files area and Modules of every active course; courses that hide Files fall back to Modules.
- Match the deck to the lecture: every deck in the course is ranked by text overlap with the transcript and by how much it looks like a deck (worksheets and syllabi rank low); a picker confirms, or automatic mode attaches the clear winner. Deck text is cached so matching is instant after the first run.

**Summaries**
- Ollama writes key points with timestamps, definitions, formulas, announcements and review questions from the transcript and the chosen deck.

**Notes**
- One note per lecture (`Courses/<course>/<date>.md`) linked from the course note, or sections under date headings in one note per course. Attachments go to `Courses/<course>/attachments` by default.
- Import existing notes: a single note (or selection) becomes a lecture with your text under *My notes*, a whole folder at once, or a running note with many dated entries split into one lecture per date. Slides are matched and summaries written from your notes.
