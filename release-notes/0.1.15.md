- **Hide courses.** Under *Settings → Canvas → Course names in the vault*, the eye button next to a course hides it: it leaves the course list, is never matched to a typed name, and is skipped by the daily pull. For courses you are enrolled in but will never record. Press the eye again to show it.
- **Course list shows vault names.** The course box listed every Canvas course under its full Canvas title even when you had given it a short name, so a renamed course showed up twice (title and short name). It now lists the short name only.
- **Course codes are remembered.** Typing a course's code (e.g. `CSCI-578-A`) in the course box used to be ignored as a preference, so later pulls filed under the full Canvas title and the course ended up in two folders. The code is now saved like any other short name.
- The *sections in the course note* layout resolves per-course note overrides through the alias too.
