- **Slides linked from Canvas Pages.** Decks that a course posts as a link on a page (e.g. "Unsupervised Learning - slides" on a weekly overview page) are now found, also when the Files tab and the Pages list are hidden from students: the plugin reads the pages that Modules link to and collects the Canvas files they point at. A page link that says "slides" marks the file as a deck, and the picker shows which page it came from.
- **One-sentence summary per day.** Summaries start with an *In one sentence* section, and the course (or meeting series) note shows that sentence next to each day's link. Run **Rebuild course note links** to add sentences for lectures summarized earlier (taken from their first key point).
