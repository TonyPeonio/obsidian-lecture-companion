- **Course notes live in their course folder.** The course note is now `<folder>/<course>/<course>.md`, next to that course's lectures, so the course folder holds one folder per course and nothing else. Course notes from earlier versions (`<folder>/<course>.md`) are moved into their folders once, on the first start, and links to them keep working. Only notes that have a course folder beside them, or carry the plugin's Lectures/Meetings list, are moved; your other notes stay where they are.
- **Rename a course.** New command **Rename a course** renames the course folder and its course note (e.g. `ADVANCED SOFTWARE ENGINEERING-…` → `Advanced Software Engineering`), sets `course:` in its notes, keeps links working, and saves the new name for the Canvas course, so new lectures and slide pulls use it.
