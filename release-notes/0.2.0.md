- **Course vocabulary for Whisper.** Each chunk's prompt now starts with a short glossary for the course being recorded: the course name and code, its teachers (Canvas), distinctive terms from this lecture's slides (else the last lecture's), terms defined in recent summaries, and words you add under Settings → Whisper → *Extra vocabulary* (`Machine Learning = Prof. Nguyen, Kullback-Leibler`). It is capped at 80 words and comes before the transcript tail, so it fits Whisper's 224-token prompt.
- **Clickable timestamps.** In a lecture note, clicking `**[12:34]**` in the transcript or a `[12:34]` citation in the summary plays the recording from that moment, in reading view and live preview (Alt-click to edit instead). The embedded player is used when it is on screen, else a small player opens in the corner. Note text is unchanged.
- **Mark moments while recording.** ⭐ *Important* and ❓ *Confusing* buttons in the panel and as commands (assign hotkeys) add `**[m:ss]** ⭐ Important` / `❓ Confusing` lines to the transcript. The summary prioritises important parts and explains confusing ones more thoroughly.
- **Catch me up.** While recording, the panel's *Catch me up* button (and command) summarizes the last 5 minutes (setting) of the live transcript. Shown in the panel; *Add to My notes* keeps it.
- **Transcript linked to slides.** After a deck is matched (or chosen), transcript paragraphs get `[[deck.pdf#page=12|slide 12]]` links where the slide changes, from TF-IDF similarity between each paragraph and each page and a mostly-forward page order. New command *Link transcript paragraphs to slides in this note* for existing notes. Setting: *Link the transcript to the slides*.
- **Questions from class.** Short turns ending in "?" after a pause are marked `**Q:**` in the transcript and listed under a new *Questions from class* summary section. A heuristic, not speaker recognition; see the README for its limits. Setting: *Mark questions from class*.
- **Exam review notes.** *Make a review note*: pick a course and a date range; writes `Courses/<course>/Review <from>–<to>.md` with each lecture's one-sentence summary and key points, all terms and definitions, review questions and questions from class, linked back to the lectures, and optionally an overview written by the model.
- **Reminder at class time.** From a weekly schedule in settings (`Machine Learning = Mon Wed Fri 10:00-10:50`) and/or Canvas calendar events, a couple of minutes before class: "Machine Learning starts in 2 min. Record?" Record fills in the course and date and starts; it never records without the click. Settings → *Class reminders*.
- **Rename a course** also renames recordings named after the course and repoints their embeds.
- **Local Vault Agent.** *Ask about this lecture* (panel button and command) opens Local Vault Agent's chat about the note. Settings → Summaries can copy Local Vault Agent's Ollama URL and model. The plugin now exposes `app.plugins.plugins["lecture-companion"].api` (`courses`, `lectures`, `transcript`, `transcribe`, `ollama`), documented in the README.
