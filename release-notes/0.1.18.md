Record a lecture that plays on the computer: Zoom, Teams, a YouTube video.

**New**
- **Audio source** (Settings → Recording): *Microphone* (as before), *This computer's audio* or *Both*. "This computer's audio" captures what the computer is playing through Chromium's desktop capture, so a remote lecture on Zoom or Teams, or a recorded one on YouTube, is transcribed without a microphone in the room; *Both* mixes it with the microphone for a hybrid class where you also want your own questions. The Opus copy saved next to the note records the same mix.
- Windows and Linux only for the system source: macOS does not let apps record their own output, and the plugin says so and points to a free virtual device (BlackHole) that you then pick under *Microphone*. The same fallback (Stereo Mix, VB-Cable, a PulseAudio monitor) works anywhere the desktop capturer is not available.

**Changed**
- Start errors say what failed and where to fix it: refused microphone, refused screen capture, a microphone that is no longer plugged in, or a capture with no audio track.
- The panel's level meter is labelled *Audio* rather than *Mic*.
